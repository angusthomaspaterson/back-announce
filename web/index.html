Settings

A GitHub token lets this device save cards, pause sources and mark things seen. It is kept on this device only, and only ever sent to GitHub.

How to make a token
  1. On this device, open github.com/settings/personal-access-tokens/new and sign in.
  2. Token name: Back Announce, plus the device, for example Back Announce Pixel.
  3. Expiration: pick the longest option offered, and note the date.
  4. Repository access: choose Only select repositories, then pick back-announce.
  5. Permissions: open Repository permissions, find Contents and set it to Read and write. Leave everything else alone. GitHub adds Metadata (read only) by itself; that is expected.
  6. Press Generate token, copy it, paste it in the box above and press Save token.

Treat it like a password. Make a separate one for each device, so you can cancel one without affecting the other.
