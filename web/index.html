Radio shows, mixes, podcasts and writing from about 150 sources you chose, in one timeline, plus what's live now on your stations. Everything lives in your GitHub repository back-announce; this app and any other device read and write the same copy.

Set up each device once

  1. Install it. On the Pixel, open the site in Chrome, tap the three dots, then Add to Home screen and Install. On the laptop, use the install icon at the right of Chrome's address bar.
  2. Turn on saving. Tap the Settings button (the two sliders, top right), paste a GitHub token and press Save token. Settings has the steps for making one under "How to make a token". Make a separate token for each device.
  3. Without a token the app still works, but read only: no Save, Pause or Mark all seen.

Feed

  • Newest first, under day headings in Perth time. New marks anything since you last pressed Mark all seen; the number on the Feed tab counts them.
  • Tap a card's text to read all of it. On a First Floor recommendations card this also lists each record with its link.
  • Tap the round initials or the source's name to see everything stored from that source. Back returns you to the same spot.
  • Group chips (Bass, NTS, Writing and so on) hide or show a group. This is remembered on this device only.
  • Open goes to the episode or article. Play plays it in the player at the bottom; the lock screen shows it, with play, pause, back 15 seconds and forward 30.
  • Save (the heart) keeps a full copy in Saved, so it stays after the episode drops out of the feed.
  • Pause source hides that source on every device. It is still gathered, so resuming it brings its recent episodes straight back.
  • Every Save, Pause and Mark all seen shows a message at the bottom with Undo.
  • Refresh (the circular arrow, top right) fetches the latest feed and any changes from your other device. It also happens by itself when you come back to the app after a few minutes.

Saved

  • Tap the Saved chip at the start of the row. Newest saves first, under the day you saved them.
  • Tap the heart to remove one; Undo brings it back.

Sources

  • Tap the Sources chip at the end of the row. Each source has a switch; Pause group and Resume group do a whole group.
  • All, Following, Paused filter the list. Keep only my original 20, the "added 1 Oct" and "added 11 Oct" buttons and Resume everything work on whole batches.
  • The right-hand column shows the date of the newest item, or failed (the last fetch didn't work, the older items are kept), or link only (the site refused the gatherer, and the card opens the site instead).
  • Tap a name to open that source's page.

On Air

  • On now with time left, Next 24 hours, and This week by day. Everything is in Perth time, and UK, Sydney and Berlin clock changes are handled automatically.
  • Station chips hide or show a station on this device.
  • Listen live opens the station's own player. Play here plays it in the app, and the lock screen shows the show on now, updating when the next one starts.
  • Copy stream copies the address for a radio app. triple j, Double J and FluxFM can't play inside the app; use Listen live for those.

Offline

The app keeps the last feed and your recent pictures, so it opens with no signal. Saves and pauses made offline are sent when the connection is back. Playing audio needs a connection.

When things update

  • The feed is gathered on GitHub every six hours, at about 2:17, 8:17, 14:17 and 20:17 Perth time. GitHub sometimes runs these a little late.
  • The Substack newsletters (First Floor, No Tags, Futurism Restated, Tone Glow, Erratic Aesthetic, and five you've paused) are gathered by the laptop every three hours while it's on, because Substack turns GitHub away.
  • The app picks up a new gather a few minutes after it finishes.
  • Your saves and pauses reach GitHub a couple of seconds after you tap. The status line says "saving…" until they have.

If something looks wrong

  • The status line says "not saved". Open Settings; it says why. Usually the token has expired, so make a new one and paste it in.
  • The "Updated" time is more than about seven hours old. On GitHub, open the repository's Actions tab and choose Gather the feed. If a yellow banner says it was disabled, press Enable workflow. Then press Run workflow.
  • The Substack sources are behind. The laptop has been off; they catch up next time it's on.
  • A source says "failed" for days. The site may have moved its feed. Ask Claude in the back-announce folder to look into it.
  • You see an old version of the app. Close it fully and open it again.

Adding a source

  • On the Sources screen, tap + Add source and paste a link. Or, in another app such as NTS, SoundCloud, Mixcloud or Apple Podcasts, tap Share and choose Back Announce.
  • Links that work: NTS and Rinse FM shows or episodes, Mixcloud and SoundCloud accounts or tracks, Apple Podcasts shows, any podcast or newsletter feed, Substack newsletters, and magazine websites that publish a feed. Spotify, YouTube and Bandcamp pages don't have feeds.
  • GitHub checks the link, which takes about a minute, then shows the latest episodes. Check the name, pick a group (or make a new one) and tap Add to Back Announce. Its episodes arrive a few minutes later.
  • If you already follow it, the app says so and takes you to its page.
  • To rename, regroup or remove a source, ask Claude in the back-announce folder for now.

SoundCloud and Mixcloud links

On the Pixel, SoundCloud and Mixcloud links open in their own apps. If either app isn't installed, the link opens the website instead.

Settings

A GitHub token lets this device save cards, pause sources and mark things seen. It is kept on this device only, and only ever sent to GitHub.

How to make a token
  1. On this device, open github.com/settings/personal-access-tokens/new and sign in.
  2. Token name: Back Announce, plus the device, for example Back Announce Pixel.
  3. Expiration: pick the longest option offered, and note the date.
  4. Repository access: choose Only select repositories, then pick back-announce.
  5. Permissions: open Repository permissions, find Contents and set it to Read and write. Leave everything else alone. GitHub adds Metadata (read only) by itself; that is expected.
  6. Press Generate token, copy it, paste it in the box above and press Save token.

Treat it like a password. Make a separate one for each device, so you can cancel one without affecting the other.
